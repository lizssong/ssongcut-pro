## 쏭컷 스튜디오 PRO

**처음 열면** 샘플 '강의 현장'으로 만든 '민경 님 시그니처' 프로젝트가 이미 놓여 있어, 파일 없이도 ▶ 재생·수정·내보내기를 바로 해 볼 수 있습니다.

### 4대 앱 장점 통합
- **캡컷**: 멀티트랙 타임라인, 클립 드래그·트림·분할(S)·복제·삭제, 빠른 비트 템플릿
- **프리미어**: 정밀 인스펙터(색감 LUT 8종 + 밝기·대비·채도·따뜻함·비네트·그레인·블러), 클립 속도 0.5~2배, 전환 10종, 비율 9:16/16:9/1:1/4:5
- **Instagram Edits**: 감성 심플 템플릿, 여백·소프트 페이드, 감성 명조체 자막
- **블로(VLLO)**: 둥근 고딕 + 파스텔 말풍선 자막, 데일리 파스텔 템플릿

### 바로 만들기(원클릭 마법사)
소재(샘플 3종 / 내 미디어 / 지금 파일 고르기) → 한 줄 문구·주제·마무리 문구 → 템플릿 6종 중 선택 → **[바로 영상 만들기]**.
컷 자동 배치, 전환, 자막 3~4개, CC0 배경음악까지 한 번에 타임라인에 세팅되고 바로 재생됩니다.

### 템플릿 6종
1. `Edits 감성 심플` — 미니멀 타이포, 소프트 페이드, 여백
2. `민경 님 시그니처` — 감성 명조 + 민트 `#34D399` 대괄호 강조, 3초 후킹 → 핵심 → CTA
3. `블로 데일리 파스텔` — 둥근 고딕, 파스텔 알약 말풍선
4. `캡컷 다이나믹 비트` — 빠른 컷, 네온 볼드 자막, 플래시 전환
5. `프리미어 시네마틱` — 레터박스, 필름 톤, 하단 자막 (16:9)
6. `감성 브런치·에세이` — 세로 감성 자막, 따뜻한 그레인 (4:5)

### 자막
- 자막 클립 추가(재생 위치) · 실시간 텍스트 수정 · 글꼴(명조/고딕/둥근체/제목/손글씨) · 크기 · 자간 · 색 · 그림자 · 배경(알약·박스·띠·형광펜) · 위치(위/가운데/아래) · 등장 모션 8종
- `*별표*`로 감싼 말은 강조색, **대괄호 강조**를 켜면 `[충분했어요]`처럼 민트 대괄호가 붙습니다
- **현재 스타일 모든 자막에 일괄 적용** / **현재 필터·전환을 모든 클립에 일괄 적용**

### 내보내기
Canvas `captureStream` + `MediaRecorder`로 타임라인을 실시간 녹화해 **실제 동영상 파일(MP4, 브라우저가 MP4를 못 쓰면 WebM)** 로 저장합니다. 1080p/720p, 소리 포함 여부 선택, 진행률 표시, 완성 후 미리보기·파일 저장.

### 그 밖에
- 내장 샘플 3종(강의 현장 5컷 / 감성 브이로그 5컷 / 전자책 4컷) — 파일 업로드 없이 바로 체험
- 사진·영상 드래그 앤 드롭 업로드(브라우저 안에서만 처리, 서버 전송 없음)
- 되돌리기/다시 실행(Ctrl+Z / Ctrl+Shift+Z), 타임라인 줌, 안전 영역 보기, 계정 표시 토글
- 키보드: `Space` 재생, `S` 분할, `Del` 삭제, `←/→` 1프레임 이동

## 실행
정적 파일이라 `index.html`을 그냥 열어도 되고, 로컬 서버로 열면 더 안정적입니다.

python3 -m http.server 8000
# http://localhost:8000/index.html
